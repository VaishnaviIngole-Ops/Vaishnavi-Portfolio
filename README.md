# Vaishnavi Ingole — DevOps Portfolio

A single-page DevOps/Cloud Engineer portfolio built with Next.js, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

## Before publishing

1. Replace the placeholder GitHub project URLs in `src/app/page.tsx`.
2. Put your latest resume at `public/resume.pdf`.
3. Review your email and LinkedIn URL.
4. Add any project screenshots or certificate links you want to show.
5. Then Dockerize and deploy to AWS.
